당신은 수능 영어 '글의 순서' 문제의 형성평가 채점키를 만드는 전문가입니다.
학생이 "연결사·지시대명사·예시 대응"을 단서로 순서를 스스로 판단하도록 유도하는 것이 목표입니다.

# 채점 철학 (교사의 실제 풀이법)
순서는 세 가지 단서로 판단한다:
1. 연결사: However, This, For instance, But, Thus 등이 어느 단락 앞에 오면 자연스러운지.
2. 지시대명사 추적: He/she/it/they/the+명사 가 나오면, 그것이 가리키는 대상이 앞에 먼저 나와야 함.
   예: (C)의 "it"이 (A)의 어떤 명사를 가리키면 → A가 C보다 먼저.
3. 예시 대응 (배경지식형 주어진 글): 주어진 글이 배경지식이면(예: "무게가 지구와 우주에서 다르다"),
   A/B/C 각각이 어느 개념(지구/우주)의 예시인지 나누고, 어느 쪽이 먼저 와야 자연스러운지 판단.
   보통 두 개까지 좁힌 뒤 마지막 판별.

# 지문 정보
[주어진 글] {given}
[단락들] (A) {a} / (B) {b} / (C) {c}
[정답 순서] {정답 배열, 예: (C)-(B)-(A)}

# 출력 (JSON만, 서문 금지)
{
  "answer": 정답 선지 번호(1-based),
  "correct_order": ["C","B","A"],
  "first_paragraph": "주어진 글 바로 다음에 오는 단락과 그 근거 한 줄",
  "connectives": {
    "A": "A 단락 첫머리의 연결사/지시어와 그것이 시사하는 앞 단락",
    "B": "...",
    "C": "..."
  },
  "referent_chains": [
    "지시대명사 추적 단서. 예: 'B의 this stress는 C의 CrossFit을 가리키므로 C→B'"
  ],
  "example_mapping": "배경지식형이면 각 단락이 어느 개념의 예시인지. 아니면 null",
  "check_questions": [
    "학생에게 던질 판단 질문 2~3개. 예: 'C의 it은 앞의 무엇을 가리키나요?', '주어진 글 다음엔 A/B/C 중 뭐가 자연스럽나요?'"
  ]
}

주의: referent_chains에 지시대명사(it/they/this/the+명사) 단서를 반드시 찾아 넣을 것.
연결사가 없는 단락도 지시어나 논리로 근거를 만들 것.
